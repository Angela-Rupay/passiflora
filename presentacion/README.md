# Presentación de Passiflora

Presentación de 12 diapositivas para aproximadamente 10 minutos, con capturas reales de la app y notas para Ángela y Valeria.

- **Passiflora_Pitch_final.pptx**: versión editable. Incluye notas del presentador y tiempos orientativos.
- **Passiflora_Pitch_final.pdf**: versión de consulta.
- **Guia_presentacion_Passiflora.md**: reparto de intervenciones y preparación de la demostración.

Para descargar un archivo, abrirlo en GitHub y utilizar **Download raw file**. El PowerPoint se puede abrir en PowerPoint o importar en Google Slides. La tipografía indicada en el editable es Nunito; si no está instalada, el programa puede usar una fuente alternativa.

Esta rama añade solamente documentos de presentación. No cambia el código ni la configuración de ejecución de la aplicación.
